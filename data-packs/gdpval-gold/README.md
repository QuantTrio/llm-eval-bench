# GDPval gold local-build descriptor pack

Builds an occupation-balanced 200-task descriptor subset from `openai/gdpval` revision
`11e7900cdcac61bc4daf59e65feb238acda98fbf`. Reference files and gold deliverables must be baked
into the matching remote artifact-executor image. Upstream does not declare an SPDX license in
the dataset card, so generated data and wheels remain local-only.
